    \begin{itemize}
        \vspace{-0.3cm}\item Designed a typed DSL for describing GUI component hierarchies, using type class constraints to enforce valid parent-child relationships at compile time.
        \vspace{-0.3cm}\item Encoded component-specific property constraints in the type system to prevent invalid property assignments.
        \vspace{-0.3cm}\item Implemented an interpreter to translate DSL descriptions into sequences of rendering commands.
    \end{itemize}

{\bf Bare-Metal AVR Breakout Game }
    \begin{itemize}
        \vspace{-0.3cm}\item Developed a Breakout-style game in C for an ATmega328P microcontroller using bare-metal programming.
        \vspace{-0.3cm}\item Designed a custom PCB in KiCad, manufactured through JLCPCB and assembled and tested the hardware.
        \vspace{-0.3cm}\item Implemented 8x8 LED matrix multiplexing, timer and external interrupt handling and button input.
    \end{itemize}

{\bf Native Serial File Transfer Application }
    \begin{itemize}
        \vspace{-0.3cm}\item Developed a native Windows GUI application in C using the Win32 API to transfer files over serial connections.
        \vspace{-0.3cm}\item Tested on Windows 2000 through Windows 11 without requiring additional DLL dependencies.
    \end{itemize}

{\bf Typed CLI Input Library in Haskell }
    \begin{itemize}
        \vspace{-0.3cm}\item Designed a typed API for interactive command-line input, supporting extensible parsing and validation through type class instances.
        \vspace{-0.3cm}\item Implemented a custom AskT abstraction with Functor, Applicative and Monad instances to compose input workflows, including conditional prompts and optional values.
    \end{itemize}
